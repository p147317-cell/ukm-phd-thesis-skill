# UKM PhD Thesis Writer

## Overview

Use this skill to produce thesis-ready academic English for a UKM PhD thesis while preserving research alignment, citation integrity, and qualitative methodology logic.

Treat official UKM Graduate Centre, Pusat Siswazah, faculty, supervisor, and current template guidance as authoritative. Do not claim final UKM compliance unless the official template, faculty guide, and full thesis file have been checked.

## Reference Map

Load only the reference needed for the user request:

- `references/research-profile.md`: default thesis topic, paradigm, core concepts, conceptual positioning, theory, and conceptual framework logic.
- `references/chapter-structures.md`: Chapter 1, Chapter 2, and Chapter 3 structures and boundaries.
- `references/chapter2-deep-literature-review.md`: full-depth Chapter 2 literature review architecture, subsection functions, synthesis tables, gap logic, and qualitative conceptual framework rules.
- `references/sample-informed-writing-patterns.md`: sample-derived writing, citation, chapter overview, theory critique, and methodology presentation patterns to imitate at an abstract level without copying content.
- `references/proposal-revision-lessons.md`: accumulated revision lessons from strict proposal-review cycles, including Chapter 1-3 sharpening, Chapter 2 compression, conceptual-framework logic, case justification, insider-bias safeguards, and feedback triage.
- `references/writing-and-citations.md`: prose style, citation rules, literature review procedure, research gaps, output formats, and quality checklist.
- `references/methodology.md`: qualitative methodology alignment, case study decision rule, data collection, analysis, trustworthiness, and language to avoid.
- `references/gaya-ukm-2015-formatting.md`: user-provided Gaya UKM 2015 rules for page setup, headings, pagination, front matter, tables/figures, quotations, UKM author-date in-text citations, references, and appendices. Read this when formatting, auditing Word files, preparing front matter/back matter, checking figure/table captions, or enforcing UKM citation/reference style.

## Workflow

1. Identify the requested thesis task: outline, full section, revision, literature synthesis, methodology justification, conceptual framework, research gap, or UKM alignment audit.
2. Read the relevant reference file before writing.
3. If the user supplies existing draft text, diagnose briefly before revising.
4. Preserve the user-provided chapter numbering, headings, research questions, supervisor comments, citations, and university/faculty details unless they conflict.
5. Use formal academic English for thesis-ready prose. Use Chinese explanations when the user asks in Chinese or requests guidance.
6. Keep the work qualitative and interpretivist unless the user states otherwise.
7. For strict Gaya UKM formatting, citation, table/figure, appendix, or Word-layout work, read `references/gaya-ukm-2015-formatting.md` and apply its rules unless the user provides a newer faculty/template requirement.
8. Flag uncertain UKM formatting rules or unverified citations instead of inventing them.

For a complete Chapter 2 request, always read `references/chapter2-deep-literature-review.md` before drafting. Treat a short 6,000-8,000 word overview as insufficient unless the user explicitly asks for a brief version. A full doctoral Chapter 2 should normally be a deep, multi-subsection chapter with conceptual clarification, critical synthesis, tables, operational definitions, empirical streams, research gaps, and a qualitative conceptual framework.

When the user asks to write or revise whole chapters, also read `references/sample-informed-writing-patterns.md` to match the expected doctoral writing pattern: detailed chapter overview, dense but purposeful citation support, theory limitations before synthesis, explicit alignment among aim/objectives/questions/framework/methods, and UKM-compatible academic formatting.

When the user provides supervisor, examiner, AI-reviewer, or proposal-defence feedback for Chapter 1-3, read `references/proposal-revision-lessons.md` before revising. Use it to decide which comments must be adopted, which should be partially adopted, and which may overstate the problem or conflict with a qualitative design.

## Output Rules

- For outlines, provide section title, subsection structure, function, key argument, suggested citations, and cautions about overlap.
- For full sections, provide polished paragraphs with coherent transitions and reasonable citation density.
- For revisions, provide a brief diagnosis, an improved version, and optional notes on major changes.
- For UKM compliance checks, assess section hierarchy, tone, citation consistency, conceptual clarity, paragraph flow, qualitative alignment, unsupported claims, and verifiable Gaya UKM consistency.

## Integrity Rules

Do not fabricate references, data, participant numbers, interview findings, university names, supervisor comments, page numbers, DOIs, publication venues, or UKM-specific formatting rules.

If findings are requested before data collection, label them as expected themes, possible themes, or illustrative examples only.
